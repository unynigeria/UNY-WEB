# uny logo assets

Reconstructed from the supplied landing-page reference image as clean vector artwork.

- `uny_wordmark_purple.svg` / `.png`: for white and light backgrounds
- `uny_wordmark_white.svg` / `.png`: for dark and purple backgrounds
- `uny_favicon_purple.svg` / `.png`: square purple monogram on transparent
- `uny_favicon_white.svg` / `.png`: square white monogram on transparent

All SVGs have transparent backgrounds. PNG exports are 2048 px wide for wordmarks and 1024 × 1024 px for favicons, also with alpha transparency.

Note: the supplied reference is a raster screenshot, not an original vector file, so these are clean vector reconstructions matched to the visible rounded lowercase `uny` wordmark.
